Bold 'b': tag física que deixa o texto em negrito.
Strong 'strong': tag lógica que indica uma ênfase mais forte ao texto.
Emphasis 'em': tag lógica que altera o significado de uma sentença.
Itálico 'i': tag física que deixa o texto em itálico.
a: cria um link de referência. Ex: youtube
img: mostra uma imagem com um link de referência.
del: deleta uma palavra do texto. Ex: errado
s: tag física que grifa o texto, parecido com del. Ex: grifado
ins: insere uma palavra no texto. Ex: certo
u: sublinha o texto, parecido com ins. Ex: sublinhado
small: deixa o texto menor. Ex: menor
sup: serve para deixar o texto na parte superior da linha. Ex: 22
sub: serve para deixar o texto na parte inferior da linha. Ex: H2O
q: serve para fazer uma citação.

blockquote: cria um bloco de citação.
 pre: mantém a formatação do texto copiado.
code: deixa o texto com uma fonte monoespaçada.
span: muda o texto selecionado sem afetar o restante.
div: cria um bloco de texto.
